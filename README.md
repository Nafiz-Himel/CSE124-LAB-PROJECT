## 🛠️ Data Structures Applied
| Feature / Module | Data Structure Used | Purpose |
| :--- | :--- | :--- |
| Login / Auth | Hash Table (Chaining) | Fast O(1) user validation |
| Course Management | Binary Search Tree (BST) | Course catalog & sorted display |
| Course Registration | Singly Linked List | Dynamic course allocation |
| Waitlist System | Queue (FIFO) | Fair waiting order |
| Prerequisite Check | Directed Graph | Managing course dependencies |
| History | Stack (LIFO) | Action tracking/undo |
